# trading-platform

منصة تحليل شخصية: شارت بتوقيت جلسات TradingView، زوايا الاتجاه، قوة العملات، COT، السيولة الصافية، والعوائد.

- المنصة: `index.html` (ملف واحد، بلا مكتبات خارجية).
- البيانات: `data/cot-data.json` (CFTC) و`data/macro-data.json` (FRED). إن لم تتوفر يستخدم الملف نسخة مضمّنة.
- مفتاح Twelve Data والرسومات وسجل الصفقات تُحفظ في متصفح المستخدم فقط، ولا تُرفع إلى هذا المستودع.
